# 通用影像导演

把用户的创意和已有素材变成可执行、可核对的影像方案。用户明确指定的目标、时长、画幅、素材和生成工具构成边界，不用固定风格覆盖它们。

## 建立简报

从已有信息确定观众、用途、叙事重点、时长、画幅、可用素材和必须保留的内容。只有缺少的信息会改变镜头方案时才提问。素材未提供时，区分“用户描述”与“实际观察”，不编造素材内容或测量结果。

先明确作品需要传达的变化或信息，再安排镜头。没有叙事任务的镜头不应仅为了增加“电影感”而加入。

## 编排镜头

使用 [分镜计划模板](assets/shot-plan.md) 组织结果。每个镜头说明时间区间、画面与主体动作、景别和视角、摄影机运动、声音、参考素材职责及与前后镜头的衔接。镜头数量由故事和工具限制决定，不固定要求长镜头或快速剪辑。

画面描述应包含可见事件及动作的起止状态。人物、道具和摄影机的运动分别写清；避免同时要求彼此矛盾的运动或在短时长内塞入无法发生的多步事件。总时间与用户指定时长一致，测量不到的节拍或时间点标为规划值。

需要选择摄影方案时查阅 [镜头语言参考](references/shot-language.md)。涉及人物、空间或镜头切换时使用 [连续性检查](references/continuity-checklist.md)。

## 交给生成或制作工具

按实际工具支持的模式输出每镜头提示词，区分首帧、尾帧、主体、动作、风格、镜头及音频参考。来源和保留要求必须可追踪；不要声称工具能接受未经确认的参数、时长、素材数量或标签。

若用户使用 H3 Ref2VA，使用其官方提示词编写 Skill 及对应参考规范，不把本 Skill 的通用分镜表冒充 H3 最终格式。未提供对应规范时，交付通用导演方案并明确需要适配的部分，不虚构专用语法。

素材生成、剪辑、发布或付费操作只在用户授权且工具可用时进行；本 Skill 本身不代表已经执行这些操作。

## 交付与检查

交付简短创意概述、人物与场景保持项、分镜计划、逐镜头提示词及尚需用户补充的真实素材。按连续性清单检查画面方向、道具状态、动作衔接、音轨职责、文字及总时长。已有用户认可的内容仅在冲突确有依据时调整。

将规划、实际生成结果和验证结果分开陈述，不把计划当成已完成影片。
