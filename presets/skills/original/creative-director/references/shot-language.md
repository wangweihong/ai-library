# 镜头语言参考

选择镜头是为了表达关系与变化，不是堆砌术语。

| 叙事需要 | 可考虑的镜头 | 核对事项 |
| --- | --- | --- |
| 建立环境与主体位置 | 全景或带空间关系的中景 | 后续特写中的方向和距离应能衔接 |
| 看清动作与交互 | 中景、必要的近景 | 手、道具和受力接触是否可见 |
| 展现反应或材质 | 近景或特写 | 是否省略了理解动作所必需的信息 |
| 揭示信息 | 有明确起点和终点的推拉或横移 | 新信息在运动的哪个位置出现 |
| 保持观察感 | 固定镜头或有目的的轻微跟随 | 主体和摄影机不要同时无因漂移 |
| 强调主观感受 | 明确归属的主观视角 | 与角色视线及空间轴线保持一致 |

描述景别、视角、摄影机运动及焦点变化时，先说明视觉目的，再写可观察的起止状态。只有确实需要时才指定焦距、快门或光圈；它们是创作要求，不能被写成已测得的拍摄事实。
